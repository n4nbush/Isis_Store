# Isis Store

Aplicación web en Flask para gestionar el stock, las ventas y las ganancias de una tienda de ropa.

## Ejecutar localmente

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

Abrir `http://localhost:5000`.

Credenciales iniciales:

- Usuario: `admin`
- Contraseña: `admin`

La contraseña predeterminada debe cambiarse antes de desplegar la aplicación.

## Funcionalidad

- Inicio de sesión y permisos de administrador.
- Alta y eliminación de productos con foto opcional.
- Control de stock y registro de ventas.
- Dashboard con ingresos, ganancias y prendas más vendidas.
